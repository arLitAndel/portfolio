PayAuth — 간편결제 서비스를 위한 사용자 인증 서버

2026.02 — 2026.06 · 1인 개발

간편결제 서비스의 "본인확인 + PIN 인증"을 처리하는 백엔드 인증 서버입니다. 다단계 본인인증, 토큰 기반 세션 관리, 계정 보호 정책, 보안 감사 로그를 헥사고날 아키텍처로 직접 설계·구현했습니다.

  • 다단계 인증: SMS OTP 본인확인 → PIN 인증으로 이어지는 회원가입·로그인 흐름 (CoolSMS 연동)
  • JWT 토큰 관리: Refresh Token Rotation과 재사용 탐지(탈취 의심 시 즉시 폐기), 로그아웃 시 Access 토큰 블랙리스트 처리 (Redis)
  • PIN 보안 정책: 취약 패턴(연속·반복) 차단, 최근 3개 재사용 금지, BCrypt 해시 저장
  • 계정 보호: PIN 5회 실패 시 계정 잠금, OTP 5회 실패 시 30분 차단, OTP 재인증 + PIN 재설정으로 잠금 해제
  • 보안 감사 로그: 접속·인증·PIN 변경 이력 기록 및 조회 API
  • 확장 가능한 본인인증 구조: 다날/KCB 등 외부 기관을 포트/어댑터로 분리하고, 로컬은 Mock 어댑터로 개발
